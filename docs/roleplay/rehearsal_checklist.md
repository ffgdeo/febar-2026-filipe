# Roleplay rehearsal checklist

- [ ] Open deck, app, and a backup text evidence file.
- [ ] State customer, problem, outcome, and demo route before clicking.
- [ ] Keep the live path under 10 minutes.
- [ ] Use tell-show-tell on every page.
- [ ] Say “synthetic prototype estimate,” not customer result.
- [ ] Say historical uplift is observational and predicted uplift is not causal.
- [ ] Explain inventory as feasibility context, not supply automation.
- [ ] Show governed price/cost versus planner-editable inputs.
- [ ] Show Unity Gateway narrative metadata and human approval.
- [ ] Show Genie generated SQL or explain how the answer is grounded.
- [ ] Be ready for value, cost, risk, integration, security, and data-quality objections.
- [ ] Switch altitude: outcome first for the executive, architecture and controls for the technical stakeholder.
- [ ] Close with pilot scope, KPIs, and a clear decision request.
