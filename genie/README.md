# Cleany PromoFlow Genie Agent

Space `01f1e1d21180156faa5560a01158c566` serves commercial leaders, promotion planners, and data teams using five Gold products: event calendar, imported plans, opportunities, historical promotion explorer, and feasibility.

The configuration distinguishes observational historical uplift from predicted future uplift; treats historical `modeled_uplift_rate` as percentage points; distinguishes imported plans from modeled opportunities; describes readiness without recommending supply actions; and provides validated example SQL and a governed opportunity-to-feasibility join.

The app embeds Genie using the `dashboards.genie` user scope.
